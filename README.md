# Tech Store — Pre-entrega React + Vite

## Requisitos
- Node.js (versión LTS recomendada)
- npm

## Ejecutar el proyecto
1. Abrí una terminal en la carpeta `mi-tienda`.
2. Ejecutá `npm install`.
3. Ejecutá `npm run dev`.
4. Abrí la URL local que muestra Vite en la terminal.

## Compilar
Ejecutá `npm run build`.

## Qué incluye
- Layout con Header, NavBar y Footer con tres tarjetas de equipo.
- Catálogo desde `public/productos.json` usando `fetch` y `useEffect`.
- Componentes reutilizables para productos.
- React Router con `/`, `/productos`, `/producto/:id` y `/carrito`.
- Context API para el estado global del carrito.
- Indicador de cantidad en CartWidget.
- Diseño responsive básico.

Los productos, imágenes y precios son datos de ejemplo para la pre-entrega.
